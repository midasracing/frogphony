## Original draft notes

This version preserves the approved PNG byte-for-byte; it does not redraw or replace the character. The original image is embedded into the .riv. A triangulated Rive mesh provides motion, while retaining its original proportions and colours at rest.

Artboard: `Kumka`. State machine: `KumkaController`.
- `Idle`: 4-second loop, subtle breathing, without deforming the face.
- `Wave`: 1.5-second deformation of the raised hand.
- `Success`: 1.25-second hop, with a squash on landing.
- `Encourage`: 1.5-second gentle lean.
Triggers: `wave`, `success`, `encourage`, each returning to Idle.

Built with official Rive CLI 1.8.0, no scripts in the runtime file. Source is `scene.rml`, generated by `build-scene.py`; it contains an embedded-image reference and editable mesh vertices and keyframes.

Run `rive . --verify`, `rive inspect . --summary`, `rive . --screenshot --advance=1`, or `rive . --once`.
Archived build only; do not copy it over the current runtime asset. This is an unsigned local build; verify compatibility with the chosen web runtime before integration. The .riv is not an editable .rev export.

A signed runtime export and editor .rev require sign-in to the official CLI (`rive . --publish --rev=build/kumka.rev`). Cloud push needs an explicitly selected project/file.

Both this raster-mesh draft and the earlier simplified vector draft are superseded by `../kumka-animation`.
